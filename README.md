# BioPhysLab

**BioPhysLab** — живой учебный мультитул по биофизике для студентов-медиков.

🌐 **Онлайн-версия:** https://biophyslab.ru

Приложение анализирует ЭКГ, помогает решать задачи и объясняет биофизические явления. AI-ключ хранится только на сервере.

## Стек

- **Backend:** FastAPI, PostgreSQL, SQLAlchemy async, Alembic
- **Frontend:** React, Vite, TypeScript, Tailwind CSS, Manrope
- **AI:** `claude-opus-5` через OpenAI-совместимый прокси `moduleapi.pro`

## Возможности

- 6 модулей: **ЭКГ**, **Задачи**, **Объяснения**, **Калькулятор Нернста**, **Статистика**, **История**
- Авторизация через JWT
- История запросов
- Шаринг результатов по ссылке
- Экспорт результатов в PDF
- Safety Guard: обработка только медицинских и биофизических вопросов
- Рендеринг формул LaTeX через KaTeX
- Тёмная и светлая темы
- Адаптивный интерфейс для мобильных устройств

## Быстрый старт

### Backend

```bash
# 1. Запустить PostgreSQL
# Порт базы данных на хосте: 5434
docker compose up -d

# 2. Создать окружение и установить зависимости
py -m venv .venv
.venv\\Scripts\\activate        # bash: source .venv/bin/activate
pip install -r requirements.txt

# 3. Создать конфигурацию
copy .env.example .env        # bash: cp .env.example .env
# Заполнить AI_API_KEY и настройки прокси в .env

# 4. Применить миграции
alembic upgrade head

# 5. Запустить API
uvicorn app.main:app --reload
```

Проверка API: открыть http://127.0.0.1:8000/health. Ожидаемый ответ:

```json
{"status":"ok","service":"BioPhysLab"}
```

### Frontend

Во втором терминале из корня проекта:

```bash
cd frontend
npm install
npm run dev
```

Открыть http://127.0.0.1:5173.

Для production-сборки:

```bash
cd frontend
npx tsc -b
npm run build
```

## Конфигурация AI

Ключ и адрес прокси задаются только в серверном `.env`:

```dotenv
AI_PROVIDER=openai
AI_MODEL=claude-opus-5
AI_BASE_URL=https://moduleapi.pro/v1
AI_API_KEY=...
```

Не добавляйте `.env` и реальные ключи в Git.

## API-эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | Проверка доступности сервиса |
| GET | `/api/stats` | Агрегированная статистика |
| POST | `/api/ecg` | Анализ изображения ЭКГ, JPG/PNG до 5 МБ |
| POST | `/api/solver` | Пошаговое решение задачи |
| POST | `/api/explain` | Объяснение темы на выбранном уровне |

AI-эндпоинты ограничены rate limit: 30 запросов в час на cookie-сессию.

## Ограничения

- BioPhysLab — учебный инструмент и **не заменяет консультацию врача**.
- AI может ошибаться в решениях, объяснениях и интерпретации ЭКГ; проверяйте ответы по учебнику и у специалиста.
- Не загружайте реальные персональные данные пациентов.
- AI-ключ хранится только на сервере и не должен попадать во frontend или Git.
- Rate limit — 30 AI-запросов в час на cookie-сессию.
